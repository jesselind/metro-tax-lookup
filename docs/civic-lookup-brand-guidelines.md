# Civic Lookup - brand guidelines

Live site: https://civiclookup.com

For design, social, and marketing. This document is AI-generated. Please clarify any issues or conflicts with Jesse Lind.

---

## Names

Product name: Civic Lookup (Civic Lookup™)

Tagline: FOR THE PEOPLE

Home line (Own): See where your property tax is actually going. And why.

Owner: Jesse Lind

Product vs campaign: Civic Lookup uses indigo. Jesse Lind for Assessor
(https://jesselindforassessor.com/) uses green. Do not use campaign green for
routine Civic Lookup social or print.

---

## Logos

Attach SVG/PNG with this handoff (not all files live in the app repo): wordmark,
optional wordmark + tagline lockup, icon/mark, social avatar, share image if needed.

- Prefer the wordmark on white or light backgrounds.
- Do not recolor it to campaign green for Civic Lookup posts.
- Do not stretch, outline, or drop it on a busy photo without a solid panel
  behind the type.
- Leave empty space around the logo so other text or graphics do not crowd it.

## Colors

Primary color: #432dd7
  Use for: buttons, Search, CTAs, focus, key accents

Primary hover: #372aac
  Use for: hover / pressed primary fill

Primary outline: #7c86ff
  Use for: outline button borders
  Strong text on light: #1e1a4d

Secondary color: #171717
  Use for: body text on white

White: #ffffff
  Use for: backgrounds; text on primary fill

Neutral border: #cad5e2
  Use for: default 1px borders and input edges

Debt / warning wash: #ffecec
  Use for: soft rose callout backgrounds (keep text dark)

Campaign green: #05995c
  Use for: Jesse Lind for Assessor disclosure only (not Civic Lookup primary)

Campaign green dark: #036b40
  Use for: campaign border + text on white

## Borders and corners

Standard border: 1px

Campaign outline: 2px (campaign disclosure only)

Focus ring: 2px

Corner radius (buttons / inputs): 6px

---

## Type

Font (Civic Lookup): Geist Sans
  Mono / code-like bits: Geist Mono

Do not substitute another typeface for Civic Lookup. Geist is free and public
(SIL Open Font License): https://vercel.com/font
(zip also on GitHub releases: https://github.com/vercel/geist-font/releases).

Font (campaign disclosure button only): Inter, 14pt bold
  Separate from Civic Lookup; for that control only.

Body size: 16px minimum
