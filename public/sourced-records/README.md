# Sourced records (committed public copies)

Official records obtained when the issuer did **not** publish a durable public file URL (for example CORA / public records responses). Served at `/sourced-records/…` so authority-chain and other product cites can use a stable `https://civiclookup.com/sourced-records/…` link residents can open and check.

**How to add documents:** see [`docs/sourced-records.md`](../../docs/sourced-records.md).

Each entity folder has a `provenance.json` (custodian, how/when obtained, hub URL, file list).
